TESECO Logo Widget - Android 9
Source project only, NOT a compiled APK.
The widget displays the provided TESECO logo via Android RemoteViews.
It must be selected by the HomeTV widget picker; compatibility with HomeTV 15.0.4 is not yet verified.
No modification to the original HomeTV APK.
Build with Android SDK + Gradle 8.9 + JDK 17, or upload repository to GitHub and run the included Actions workflow.
Install APK: adb install -r app-debug.apk
